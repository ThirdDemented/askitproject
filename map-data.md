# Bundled map geography

Natural Earth 1:110m Admin 0 countries, United States, Canada and Mexico. Public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Terms: https://www.naturalearthdata.com/about/terms-of-use/

The retained geography.js contains the original geometry coordinates for these three features and can render without network access. Road geometry is separately supplied by optional OSRM requests using OpenStreetMap data, with in-game attribution. The map depicts game progress, not GPS or live navigation. Offline endpoint connectors are explicitly estimates, not road routes.
